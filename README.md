## ⚠ ตั้งค่า Firebase ให้เสร็จก่อนแจกนักเรียน (โปรเจกต์ mae-sot-musicology-by-matang)
1. **อีเมลครู** — ตั้งเป็น `ntpwm2541@gmail.com` แล้วทั้งใน `config.js` และ `database.rules.json` (ถ้าเปลี่ยน ต้องแก้ทั้งสองไฟล์)
2. **Authentication → Sign-in method → Google → Enable** (เลือก support email)
3. **Authentication → Settings → Authorized domains → Add domain**: `ชื่อผู้ใช้.github.io` (โดเมน GitHub Pages)
4. **Realtime Database → Rules** → วางเนื้อหา `database.rules.json` ทั้งไฟล์ → **Publish**
   (ถ้าตอนสร้างเลือก test mode ฐานข้อมูลจะเปิดให้ทุกคนอ่าน/เขียน — ต้องเปลี่ยนเป็น Rules นี้ก่อนใช้)
5. อัปโหลดทั้งโฟลเดอร์ขึ้น GitHub → Settings → Pages → Deploy from branch
6. เข้า `…/teacher.html` → ล็อกอิน Google ด้วยอีเมลครู → นำเข้ารายชื่อ → จัดกลุ่ม → แจกลิงก์ `…/index.html`

> ทดลองระบบโดยไม่แตะฐานข้อมูลจริง: เปิด `index.html?demo=1` และ `teacher.html?demo=1` (ข้อมูลสาธิตอยู่ในเบราว์เซอร์นั้น เปิดหลายแท็บเพื่อจำลองนักเรียนหลายคน) · ออกจากโหมดสาธิต: `?demo=0`

## จัดการรายชื่อ (ครูเท่านั้น) — แท็บ 🧾 จัดการรายชื่อ

- ลาก ⠿ (หรือกด ▲▼) เพื่อจัดลำดับ ระบบบันทึกเลขที่ใหม่ทันที และอัปเดตเลขที่ในกลุ่มให้ด้วย · เรียงทั้งห้องตามรหัสหรือตามชื่อได้
- ✎ แก้ชื่อ/ย้ายห้อง (ย้ายห้องแล้วจะออกจากกลุ่มเดิม) · 🚪 ออก = นักเรียนย้าย/ลาออก ล็อกอินไม่ได้และไม่อยู่ในไฟล์คะแนน แต่ผลงานเดิมยังเก็บไว้ · ↩ คืนสถานะได้
- Rules ฝั่งเซิร์ฟเวอร์อนุญาตให้แก้รายชื่อได้เฉพาะอีเมลครูเท่านั้น

- ครูคลิกเลือกนักเรียน → “สร้างกลุ่มจากที่เลือก” / เพิ่มเข้ากลุ่ม / นำออก / จัดอัตโนมัติ (กลุ่มละ 4–6 คน)
- สมาชิกเลือกบทบาท (หัวหน้า, ผู้สัมภาษณ์, ช่างภาพ-เสียง, ผู้บันทึก, ผู้วิเคราะห์, ผู้เรียบเรียง) และกด “รับงาน” แต่ละชิ้น
- พบดนตรี/ชุมชนนอกรายการ (เช่น มอญ ลาหู่ พม่า ดนตรีร่วมสมัย) → เลือก “➕ อื่น ๆ (ระบุเอง)” แล้วพิมพ์ชื่อ ระบบนับเป็นชุมชนใหม่ในห้องประมวลผลกลาง รายงาน โปสเตอร์ และปฏิทิน (แก้รายการคำแนะนำได้ที่ `otherSuggestions` ใน config.js)
- ข้อมูลกลุ่มอัปเดตแบบเรียลไทม์ แก้คนละช่องพร้อมกันได้ไม่ทับกัน แสดงผู้แก้ล่าสุดทุกช่อง
- **ห้องประมวลผลกลาง**: ความพร้อมก่อนส่ง, ข้อมูลแต่ละชุมชน, ตารางเปรียบเทียบเครื่องดนตรี, สถิติสีสันเสียง/อารมณ์/หน้าที่ดนตรี, สัดส่วนการมีส่วนร่วมของสมาชิก (คำนวณจากประวัติการบันทึกจริง)
- งานรายบุคคล: สะท้อนคิด + ประเมินเพื่อน (ครูเห็นคนเดียว)

## กันข้อมูลสูญหาย
1. ทุกการพิมพ์เข้า “กล่องขาออก” ในเครื่องก่อน (IndexedDB) แล้วส่งขึ้นเซิร์ฟเวอร์ — ไม่มีสัญญาณหรือปิดแอปกลางคัน จะส่งต่อเมื่อเปิดใหม่
2. แคชข้อมูลไว้เปิดดู/บันทึกตอนออฟไลน์
3. ประวัติทุกการแก้ไข (ใคร/เมื่อไร) ย้อนกลับเป็นฉบับเก่าได้ · ถังขยะกู้คืนได้
4. เครื่องนักเรียนเก็บสำเนาข้อมูลกลุ่มอัตโนมัติ 15 ชุด + ดาวน์โหลดไฟล์สำรองได้
5. ครู: “สำรองทั้งระบบ” เป็น .json (แนะนำทุกสัปดาห์) และ “กู้คืนจากไฟล์” ที่เพิ่มเฉพาะส่วนที่หาย/ใหม่กว่า ไม่เขียนทับงานล่าสุด

- **ใบอนุญาตผู้ปกครอง** (`consent.js`): ผู้ปกครองเซ็นในแอป เลือกอนุญาต/ไม่อนุญาต, ครูบันทึกจากใบกระดาษได้, พิมพ์/บันทึก PDF หนังสือขออนุญาต, เก็บประวัติการแก้ไข — ข้อมูลอยู่ที่ `consents/{รหัสนักเรียน}/{รหัสนัด}`
- **คะแนนตามสัดส่วนการลงพื้นที่**: ผู้ปกครองไม่อนุญาต → งานภาคสนาม (สมุดภาคสนาม, สัมภาษณ์) หัก 20% × สัดส่วนครั้งที่ไม่ได้ไป (ปรับ % ที่ ⚙ ตั้งค่า; ติ๊ก “ทำงานทดแทนแล้ว” เพื่อไม่หักรายคน)
- **ตรวจความครบถ้วน**: ช่อง * คือขั้นต่ำ (ขาด = “ร่าง” ไม่นับเป็นชิ้นงาน); รายละเอียดสำคัญ (GPS ฯลฯ) ขาดได้เมื่อยืนยันพร้อมเหตุผล ครูเห็นการยืนยัน
- **บังคับการมีส่วนร่วม**: เลือกบทบาทก่อนบันทึก, งานกลุ่มต้องมีผู้ร่วมบันทึก ≥ 2 คนจึงแจ้งส่งได้, รายงานส่ง/ส่งออกได้เมื่อทุกชิ้นงานมีข้อมูลขั้นต่ำและทุกคนมีชื่อในงาน
- **กลุ่มวัฒนธรรม**: ครูเพิ่ม/แก้ไข/นำออกได้ที่ ⚙ ตั้งค่า/สำรอง (เก็บที่ `config/communities`)
- ไอคอนแอปเต็มกรอบ ไม่มีขอบขาว (ติดตั้งใหม่บนหน้าจอโฮมเพื่อให้ไอคอนเปลี่ยน)

## อัปเดต v11 — ใบอนุญาตผู้ปกครองแบบลิงก์ (แบบเดียวกับระบบชมรมสรรพวาทิต)

**ต้องเผยแพร่ `database.rules.json` ใหม่** (มีกฎของ `ctoken` และเปลี่ยนกฎ `consents`)

- ครูสร้าง/อนุมัตินัด → ระบบออกลิงก์ใช้ครั้งเดียวรายคน (`ctoken/{token}`; `consents/{sid}/{eid}` เก็บ token)
- นักเรียนเห็นปุ่ม “ส่งลิงก์ให้ผู้ปกครอง / คัดลอกลิงก์” ในปฏิทินและหน้ากลุ่ม
- ผู้ปกครองเปิด `index.html?c=token` บนเครื่องของตนเอง ไม่ต้องล็อกอิน เซ็นและส่งได้ครั้งเดียว
- ครู: ยืนยันคำตอบ, คัดลอกลิงก์ให้ใหม่, บันทึกจากใบกระดาษ, ออกลิงก์ใหม่ (ยกเลิกคำตอบเดิม), พิมพ์/PDF
- ยกเลิกการเซ็นบนเครื่องนักเรียน · ข้อมูลใบอนุญาตรูปแบบ v9–v10 (ถ้ามี) ไม่ถูกอ่านในเวอร์ชันนี้
